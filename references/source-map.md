# 信源地图：任一地区的公开渠道与检索式

同一套方法适用于全国任一省、市、县区：先按下表列出目标地区对应的机构，再逐格检索。这里只给机构类型、常见栏目和少数稳定的国家级入口，**不是域名白名单**。执行时实际打开页面，核实域名归属、机构主体、发布日期和正文，再写入证据。

## 1. 建立本地渠道清单

对每个配置地区，先用“地区名+机构名+官网”找到并记录以下机构的官方站点（直辖市多为“委/局”，省级多为“厅”，地市为“局”）：

| 渠道 | 常见机构名称 | 重点栏目 | 主要产出 |
|---|---|---|---|
| 政府门户 | 省/市/县人民政府 | 政府信息公开、政策文件、政策解读、今日要闻 | 规范性文件、重大部署 |
| 发展改革 | 发展和改革委员会（局） | 重大项目、项目审批核准备案、价格、招商引资 | 重大项目清单、集中开工、核准批复 |
| 工业和信息化 | 工业和信息化厅/局，经济和信息化局 | 通知公告、专精特新、数字化转型、技改 | 申报通知、认定名单、产业政策 |
| 商务 | 商务厅/局、投资促进局 | 招商引资、外资、开放平台、自贸试验区 | 签约项目、外资项目、平台政策 |
| 科技 | 科学技术厅/局 | 通知公告、项目公示 | 科技计划、创新平台、高企认定公示 |
| 生态环境 | 生态环境厅/局 | 环评受理公示、拟批准公示、审批决定公告 | 建设项目环评各阶段 |
| 自然资源 | 自然资源厅/局、公共资源交易中心 | 土地供应、出让公告与结果 | 工业用地出让、竞得人 |
| 住房城乡建设 | 住房和城乡建设厅/局 | 施工许可、行政许可公示 | 施工许可（判断“开工”的依据之一） |
| 公共资源交易 | 公共资源交易中心/平台、政府采购网 | 招标公告、中标候选人公示、结果公告 | 采购启动、中标、废标 |
| 财政 | 财政厅/局 | 专项资金、预算公开 | 资金分配（注意预算/拨付口径） |
| 统计 | 统计局 | 统计公报、月度数据、数据解读 | 宏观与行业统计（核对统计期与口径） |
| 国资 | 国有资产监督管理委员会 | 国企改革、重组整合 | 国企重大事项 |
| 金融管理 | 地方金融管理局、人民银行分支机构、金融监管派出机构 | 政策发布、行政处罚 | 金融政策、处罚信息 |
| 园区 | 高新区、经开区、自贸片区管委会 | 新闻动态、通知公告、项目进展 | 入驻、投产、园区政策 |

县区和园区的公开程度差异大，查不到时记“渠道不可用/未找到官方站点”，不要用转载网站代替。

## 2. 国家级与跨地区入口

| 用途 | 入口（执行时核实） |
|---|---|
| 国家政策文件 | 中国政府网（www.gov.cn）政策文件库；国家发展改革委、工业和信息化部、商务部、科技部、生态环境部等部委官网 |
| 投资项目审批备案 | 全国投资项目在线审批监管平台及各省子平台（备案/核准信息公示） |
| 企业登记与身份 | 国家企业信用信息公示系统（www.gsxt.gov.cn）；信用中国（www.creditchina.gov.cn） |
| 上市公司公告 | 巨潮资讯网（www.cninfo.com.cn）；上海证券交易所（www.sse.com.cn）、深圳证券交易所（www.szse.cn）、北京证券交易所（www.bse.cn）；香港交易所披露易（www.hkexnews.hk） |
| 新三板与债券 | 全国中小企业股份转让系统（www.neeq.com.cn）；中国货币网（www.chinamoney.com.cn）、上海清算所（www.shclearing.com.cn）的发行文件 |
| 政府采购 | 中国政府采购网（www.ccgp.gov.cn）及各省分网 |
| 金融监管与处罚 | 国家金融监督管理总局（www.nfra.gov.cn）、中国证监会（www.csrc.gov.cn）及派出机构 |
| 司法公开 | 中国裁判文书网、中国执行信息公开网（只用于法人主体必要事实，不做人身推断） |
| 统计 | 国家统计局（www.stats.gov.cn）及各省统计局 |

## 3. 覆盖矩阵与检索式

每个地区至少覆盖四格：政策通知、产业项目、企业公告、公开同业。叠加配置的企业和主题。下列检索式按需替换 `{地区}{企业}{主题}{月份}`，每格可用多个查询；一个宽泛查询不能代替整格检查。

| 格 | 检索式示例 |
|---|---|
| 政策通知 | `{地区} 人民政府 印发 通知 {月份}`；`{地区} 工业和信息化 申报 通知`；`site:{政府域名} {主题} 政策` |
| 产业项目 | `{地区} 重大项目 集中开工 {月份}`；`{地区} 环评 拟批准 公示`；`{地区} 项目 备案 {主题}`；`{地区} 工业用地 出让 结果` |
| 招标采购 | `{地区} 公共资源交易 {主题} 招标公告`；`{地区} 中标候选人 公示 {月份}` |
| 企业公告 | `{企业全称} 公告 {月份}`；`{企业证券简称} 董事会 决议`；`{地区} 上市公司 投资 项目 公告` |
| 公开同业 | `{地区} 银行 签约 {主题}`；`{地区} 产业基金 设立`；`{地区} 金融 支持 {主题} 措施` |

检索结果只是线索。对高相关候选必须打开原文；原文缺发布日期时，到同机构栏目列表或公告索引核对日期（列表日期与成文日期分开记录）。记录每格状态：已检索、已读正文、零合格、待追源或渠道失败。

## 4. 不同地区的常见差异

- **直辖市**：市级部门多称“委/局”，区级部门直接对应地市级；“全市”配置覆盖全部区。
- **民族自治地方**：自治区、自治州、自治县的机构名称带民族名称，检索时用规范全称。
- **计划单列市与副省级城市**：部分审批权限与省并行，项目备案可能在市级平台公示。
- **省直管县、县级市**：县级市（如昆山市、义乌市）政务公开较完整，可单独配置；省直管县的上级部门以省为准。
- **港澳台**：发布与披露体系不同（如港交所披露易、澳门特区政府公报），按当地正式渠道核验，日期按北京时间换算并保留原文时区。

## 5. 渠道失败时

登录墙、验证码、403、付费墙、动态模板无法读取时不绕过，记为渠道不可用，寻找同一原文的合法公开版本；仍无原文则留在待核池。渠道失败影响覆盖完整性时，必须出观察稿并在 coverage.gaps 写明哪个地区、哪类渠道未能检索。
