# 模板与图表指引

模板 = 版式（layout）× 配色（theme）。两者只改变呈现，不改变事实、筛选和证据。选择顺序：用户明确要求 > 配置 `presentation` > 下表按场景推荐 > 默认（标准版+暖纸深红）。

## 1. 三种版式

| 版式 | 结构 | 适合 | 不适合 |
|---|---|---|---|
| `standard` 标准版 | 报头 → 范围与提示 → 概况数字与图表 → 一句话速览 → 关键数字 → 政府/企业分区双栏卡片 → 专题 → 后续关注 → 证据 | 周报、月报；电脑与手机都要看 | 事项很多（>20条）的晨报 |
| `compact` 速读版 | 同上，但只出来源构成图，事项为单栏编号列表，研究关注和来源压成一行 | 晨报、手机阅读、事项多、微信转发长图 | 需要多维图表对比的月报 |
| `memo` 要报版 | 居中报头与双线 → 内容提要 → 关键数字 → “一、（一）1.”编号正文 → 专题 → 后续关注 → 证据；默认不出图，仅一行概况 | 给管理层、政府部门的报送稿；打印A4 | 需要图表说明分布的场景（可用 `charts` 打开） |

手机宽度（≤600px，含PNG长图）下标准版和速读版会把一句话速览移到图表之前；桌面与打印保持图表在前。

## 2. 四套配色

| 配色 | 气质 | 推荐场景 |
|---|---|---|
| `classic` 暖纸深红 | 报纸感、温和 | 默认；通用简报 |
| `navy` 商务蓝 | 理性、企业感 | 招商、企业战略、咨询、金融机构 |
| `ink` 素墨 | 黑白为主、朱砂点缀 | 要报版、打印、正式报送 |
| `jade` 青绿 | 清新、科技与绿色 | 科技创新、绿色低碳、新能源专题 |

每套都有浅色与深色两组令牌，`color_scheme=auto`（默认）随系统切换；需要固定浅色（如嵌入浅色系统）时用 `light`。打印和PNG长图始终使用浅色。图表三色在每套配色的浅色、深色下都经过色觉缺陷模拟校验（全部两两配对），新增配色必须重新校验。

## 3. 场景推荐

| 场景 | 版式 | 配色 | charts |
|---|---|---|---|
| 区域晨报（手机） | compact | classic或navy | 默认 |
| 区域周报 | standard | classic | 默认 |
| 月报 | standard | classic或navy | 默认，可加 `stage` |
| 管理层/政府报送 | memo | ink | `[]` |
| 招商周报 | standard | navy | `["region","theme","enterprise"]` |
| 企业或项目专题追踪 | memo | ink或classic | `["stage"]` 或 `[]` |
| 行业扫描（全国） | compact或standard | jade | `["region","stage"]` |

阅读视角目录中每个视角也给了推荐版式，可作为默认。

## 4. 图表规则

渲染器根据最终JSON自动计算，不需要也不允许在报告外手工拼图。

| 图表键 | 形式 | 默认出现在 |
|---|---|---|
| `publisher` 原始披露主体 | 分段条（部分与整体）+图例数量与百分比 | 所有含图版式 |
| `theme` 本期关注主题 | 横向条形图，按数量降序，未分类灰色排最后 | standard |
| `region` 事项所在地区 | 横向条形图 | standard的周报、月报、专题 |
| `enterprise` 涉及企业 | 横向条形图（只统计enterprise非空的事项） | standard的周报、月报、专题 |
| `stage` 事项所处阶段 | 横向条形图，按数量排序并注明“不构成漏斗” | 仅显式指定 |

- 晨报默认只出 `publisher` 和 `theme`；速读版只出 `publisher`；要报版默认不出图。
- 某维度少于2类不成图；除来源构成外，事项少于3条不成图。
- 超过7类时折叠为“其余N项”，完整分类见图下“图表数据表”。
- 条形图同一颜色（单系列），不按数值深浅上色；来源构成三色固定对应政府、企业、其他，跨报告不变。
- 概况数字（已核实事项、一手来源核实、内容主题数、日期覆盖）始终显示在图表上方，未分类条数写在主题数下方，不隐藏。
- 不画发布日期计数图、不画跨项目阶段漏斗、不画地图（地区名称不等于地理精度），不在图上叠加“编制说明”。

## 5. 关键数字与后续关注

`key_figures` 渲染为数字卡片（标签、数值、口径、依据链接），适合放本期最需要被记住的2–4个单一口径数字；没有合适数字就不填，不凑。`watchlist` 渲染为编号清单，适合周报、月报和专题；晨报可选。

## 6. 命令

```bash
python3 scripts/briefing_tool.py options                       # 查看可用版式、配色、图表与阅读视角
python3 scripts/briefing_tool.py render --data 04-final.json --out 简报.html --layout compact --theme navy
python3 scripts/briefing_tool.py render --data 04-final.json --out 简报-浅色.html --color-scheme light
python3 scripts/export_png.py --data 04-final.json --out 长图.png --layout compact
```

模板预览：`examples/gallery/` 下的三份虚构演示数据（`demo-daily.json` 速读版、`demo-weekly.json` 标准版、`demo-special.json` 要报版）可用任意版式和配色渲染查看效果。演示数据中的主体、数字和链接均为虚构，不得作为事实引用。
