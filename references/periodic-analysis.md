# 周期分析、专题模板与阅读视角

## 聚合顺序

先取发布日落在本期的已核验证据，核对有效配置，再做事件去重、主体归并、主题聚类。周月报不得从过去成品的概述直接再造证据；只有HTML、缺少原文/日期/出处的历史材料需要重建证据，不能假称已核实。max_items只截断展示卡片，分析基于全量合格底层证据；引用未展示卡片的事实时应扩展最终证据列表，展示总量上限须在配置摘要说明为“摘要卡片上限”，不可删证据来硬守卡片数。

## 三类信号

| 信号 | 可复算条件 | 不能算的情况 |
|---|---|---|
| 主题持续 | 同主题在本期≥3个不同发布日有不同实质事件/进展，列日期及ID | 同一旧稿跨日转载、同一天3篇报道 |
| 跨日新进展 | 同一主线在≥2个连续自然日各有新事实，列进展关系 | 同一公告两天转载、只改标题或抓取日 |
| 多源独立印证 | 同一事实有≥3个独立原始来源根，本期记录来源根与依据 | 省市媒体转载同一通稿、多网站同一附件 |

信号阈值仅是本技能的编辑规则，不是统计检验、风险评级或事实真实性保证。某条事实单一权威来源已核实时可以进稿，但不贴“多源”标记。同一主题不同事实的热度与同一事实的独立印证不能互换。无法证明独立性时不要打多源标签；可以写“获得多渠道关注”，但明确转载属性且不升高事实置信。

周报呈现：简洁报头与实际覆盖 → 概况数字与来源、主题、地区图 → 真实内容提炼的一句话速览 → 关键数字（如有）→ 政府/企业一级分区和部门/产业二级分类 → 周期变化及研究含义（sections）→ 后续关注（watchlist）→ 完整证据。分组可随配置删减空项，不强凑十节。速览写具体事项、变化和状态，不写条数目录；按摘要text及其evidence_ids逐句核对。图表直接由最终证据计算，不在HTML外临时拼接。

## 月报专题

优先选跨周持续、已核实政策拐点、项目里程碑、企业实质进展的主题。默认2–3个；只有1个充分就做1个。没有可论证专题时只给月度事实回顾和缺口，标观察稿，不将线索写成结论。

每题依次写：
1. 由头：本月已核实事件与ID；必要旧背景单列“背景”，不得计入当月新事实数。
2. 机制：政策如何作用到产业或企业活动，注明为分析推断。
3. 对比：只有同口径、同期数据才比较；不可比则说明限制，不补编数据。
4. 三视角：政策目标、企业响应、经营管理可关注事项。
5. 证据表：每个论断对应事实ID、原始来源、统计口径、反证及局限。
6. 条件化判断：“如某里程碑由正式公告确认，可进一步研究某服务场景”，不得写确定融资需求或审批结论。
7. 下期关注：具体需要核实的公开事项、预计披露窗口（有依据才写），写入watchlist；不自动改配置或发送提醒。

## 专题简报模板

专题简报（kind=special）用于跨越日、周、月边界的追踪，周期由用户给定（≤366天）。按用途选一种结构，sections按下表顺序编写；材料不足时少写，不凑段落。

| 模板 | 适用请求 | sections建议 | 推荐呈现 |
|---|---|---|---|
| 企业追踪 | “某公司近三个月有什么动作” | 主体与范围说明 → 按时间排列的进展（每步列ID与日期）→ 资金与口径 → 待核与反证 | memo或standard；charts=[theme, stage] |
| 项目追踪 | “某项目推进到哪了” | 项目身份（备案/环评文件号）→ 手续节点时间线 → 已公开金额及口径 → 下一节点与预计披露窗口（有依据才写） | memo；key_figures放备案投资、用地等单一口径数字 |
| 政策解读 | “某新政出台后各地怎么跟进” | 政策要点（原文条款）→ 配套与落地文件 → 可观察的企业响应 → 尚未明确的事项 | standard；charts=[region, publisher] |
| 区域对比 | “沪苏浙皖新能源汽车项目对比” | 比较口径与范围 → 各地已核实事项 → 同口径可比部分 → 不可比部分及原因 | standard；charts=[region, theme] |
| 行业扫描 | “全国新型储能本月重大项目” | 范围与检索说明（全国专题须写明未逐省检索）→ 主要事项分组 → 阶段分布（不串成漏斗）→ 后续关注 | compact或standard；charts=[region, stage] |

所有模板共用同一证据门：时间线上每个节点都要有本期已核实的事项ID；周期外的背景单列“背景”，不计入本期事实数，也不放进items。

## 阅读视角目录

阅读视角是可选配置，不是页眉。所有视角共用同一证据门和筛选结果，只调整首屏排序、展开深度和跟踪问题；页面不展示部门、岗位或内部机构名称。没有明确选择时用 `general` 通用阅读。

共同首屏：先看本期原始披露主体与实质主题，再看提炼的内容摘要。主题按产业方向、科技攻关、数智化、企业资金安排等内容归并，每条一个主theme；阶段另存stage，不把审批手续本身当成所有事项的产业主题。日期留在事实卡，不做发布日计数图。图形按数据关系选择，不强制同一套图；不同项目的阶段分布不串成漏斗或连续进度。

## 排序与数量

先按用户关注匹配解释，再按事实的可核实影响、政策期限/项目里程碑、时效性作编辑排序。输出“编辑优先级”而非虚构量化评分；若提供计分，必须公开维度/分值/每条依据并可复算。企业负面和正面均按相同证据门，不默认偏向任何主体。条目不足可少出，不将未核验内容补位。
